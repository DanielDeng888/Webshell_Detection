# NORMA：基于规范化能力表示的跨语言 Webshell 检测

本仓库用于公开论文《基于规范化能力表示的跨语言 Webshell 检测方法》的补充材料。研究面向 PHP、JSP、ASP/ASPX 等服务器端语言，尝试将不同语言、不同语法形式的程序行为映射为统一的规范化能力表示，以降低语言差异和代码混淆对 Webshell 检测的影响。

## 研究内容

NORMA 的总体流程包括：

1. 对多语言服务器端源代码进行解析并提取符号事实；
2. 将文件操作、命令执行、动态求值、网络通信等行为归一化为跨语言能力表示；
3. 通过受约束且经过验证的大语言模型候选生成，补充静态分析难以直接恢复的语义信息；
4. 构建能力图并进行图表示学习与不变性约束训练；
5. 在同语言、跨语言、混淆、消融和外部样本等设置下评估检测效果与泛化能力。

## 核心代码结构

完整实现按以下逻辑模块组织：

```text
pipeline/
├── parsers/              # PHP、JSP、ASP/ASPX 解析与符号事实抽取
├── ontology/             # 能力本体、映射规则与版本管理
├── lifting/              # 规范化能力表示生成与验证
├── graph/                # 能力图构建、编码与批处理
├── models/               # 图编码器、分类器与不变性学习模块
├── experiments/          # 主实验、消融、跨语言和鲁棒性实验
└── evaluation/           # 指标计算、审计记录与结果导出
```

上述目录仅用于说明研究实现的模块边界，当前公开版本不包含核心实现文件。

## 当前公开内容
